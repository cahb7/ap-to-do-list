Aplicação Full Stack de lista de tarefas (To-Do List) desenvolvida com Node.js, Express, MariaDB e Frontend em HTML, CSS e JavaScript, incluindo Dark Mode 🌙.
O projeto foi criado com foco em boas práticas, aprendizado prático e uso real de tecnologias utilizadas no mercado.

Funcionalidades
✅ Backend
API REST com Express
CRUD completo:
Criar tarefas
Listar tarefas
Atualizar tarefas
Deletar tarefas
Integração com MariaDB
Uso de SQL (SELECT, INSERT, UPDATE, DELETE)
Pool de conexões
CORS configurado
✅ Frontend
Interface moderna e responsiva
Criação de tarefas
Listagem dinâmica
Marcar/desmarcar tarefas como concluídas
Exclusão de tarefas
Dark Mode com persistência no LocalStorage
Comunicação com API via fetch
🛠️ Tecnologias Utilizadas
Backend
Node.js
Express
MariaDB
SQL
CORS
Frontend
HTML5
CSS3
JavaScript (Vanilla JS)
